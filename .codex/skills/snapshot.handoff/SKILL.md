# Snapshot Handoff

Use this skill when finishing a stable AIOS Codex work checkpoint.

## Snapshot

Create a snapshot after a meaningful change, build, or review checkpoint.

Recommended metadata:

- session id
- objective
- files changed
- validation commands
- next step

## Handoff

Create a handoff when another Codex runtime, agent, or future session should continue the work.

Include:

- reason for handoff
- current context
- changed files
- validation state
- next steps
