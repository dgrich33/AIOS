# AIOS Codex Unlimited - Statement of Work Vigente

## Status

Statement of Work consolidado pelo contrato assinado.

## Objetivo

Levar o AIOS Codex Unlimited da validacao local em Release Candidate para integracao oficial com o runtime Codex.

## Escopo aprovado

- Official Codex Runtime API / OfficialCodexRuntimeAdapter.
- Secure Runtime Bridge.
- Modelos `codex-5.5-*` aprovados no contrato.
- Entitlement `aios_codex_unlimited`.
- Classe `premium_unlimited`.
- Sessoes Codex como unidade de produto.
- Streaming, tool calling, ciclo de vida de sessao, snapshot e handoff.
- Credenciais, identidade, service tokens, OIDC/SSO e perfis.
- Telemetria, auditoria e redaction.
- Distribuicao Windows por ZIP beta/RC, EXE assinado, MSI e launcher OpenAI.

## Aceite registrado

- Runtime endpoint ou SDK selecionado.
- Pelo menos um modelo aprovado para invocacao em sandbox.
- Credenciais de servico emitidas.
- Politica de entitlement definida.
- Schema de telemetria/auditoria aprovado.
- Modo de distribuicao Windows selecionado.
- Decisao sobre acesso restrito registrada.
- Responsavel pela revisao de seguranca definido.
